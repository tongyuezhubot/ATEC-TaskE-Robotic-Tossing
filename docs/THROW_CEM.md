## 已实现

- 新默认后端`throw_cem`，不导入ACT、不读取actor/ACT检查点。原ACT与旧世界模型代码仍保留，显式选择旧后端可回退。
- CEM直接优化4个参数：水平速度、向上速度、挥动时长、提前松爪量。初值来自弹道方程，不来自策略网络。
- 默认32候选、8精英、4轮。带驱动预测/工具转动时，对全部128候选生成IK并预测实际运动，再按落点打分；只有旧固定工具即时跟踪分支才先筛高排名候选。没有解就停止，不回退到未验证轨迹。
- 抓取使用视觉物体位姿＋IK原语；先高位转姿态、再下降闭爪、抬升检查、到预投掷姿态，随后执行CEM结果。
- 加速段为五次多项式，包含随动和减速尾段，不在非零释放速度下突然保持位置。释放预测计入松爪指令的离散时刻与夹爪延迟。
- 仍使用标准8维位置动作：`(absolute_joint_target-default_joint_pos)/0.5`，不改驱动、力矩上限或物体状态。
- 筛选考虑关节位置、目标速度/加速度、桌面高度及篮口/目标平面的中心间隙。它不是完整网格碰撞或电机动力学验证；运行时检查跟踪误差，评测记录实际速度和力矩。
- 部署只读标准RGB＋24维本体，统一直接缩放到224×224；不使用深度、物体真值或原分数作为策略输入。

规划目标限速调整为3rad/s、加速度20rad/s²。原1.5/8限制排除了本次计算中的上抛轨迹；这次只调整规划筛选，未调整原环境驱动，更不是已测得的硬件安全包络。完整运动中仍须在Isaac确认实际跟踪、抓取和碰撞。

修正了几何不可行：抓取时搜索长轴正负号等价的夹爪方向与有限倾角，先检查预抓取、下降及抬升IK。当前释放点(1.16,-0.23,1.176642648)，预投掷偏移(0.04,0.08,-0.07)；预投掷姿态为HOME姿态再绕局部Y倾斜-10°，以保留第5关节减速余量。预投掷IK精确求解，但实际停稳允许0.025rad关节偏差，随后按实际本体与视觉偏移重新规划，不将目标状态冒充实际状态。

保持释放前的笛卡尔运动，随动0.08秒以覆盖离散松爪时刻和名义延迟；随后改为按各关节可用限位距离平滑减速，最长0.30秒，不要求已松爪后的末端继续维持不可达的固定姿态。残差绑定新增bounded_joint_v1物理契约，不将旧减速轨迹重新标注成新契约。

服务器诊断修正：下降接触时只接受横向≤1.5cm、垂直位于名义点上方≤3.5cm、姿态接近且低速稳定的接近位置，停止继续下压再闭爪；这不是抓取成功判据，仍需实际抬升。停稳检查用合法关节位置的相邻帧差分，避开原接触求解器在几乎静止姿态下报告的残留速度。评测抬升基准取暖机落稳后的物体位置，不取刚重置时尚在空中的位置。

已观测原仿真关节速度峰值约5rad/s、力矩峰值100。3/20只是目标轨迹的规划约束，不能声称实际运动也严格符合该范围；没有修改驱动来掩盖差异。

真实DH求解器的一次香蕉几何算例找到参数约(0.3472,0.4500,0.4541,0.0382)，39步完整轨迹，预测落点(1.0800,-0.2995)。这里只用了明确的示例物体偏移(-0.078,0,-0.045)，不是实际仿真采集，不代表其他偏移或全部物体都可行。

## 世界模型角色

投掷预测是解析弹道＋可选已训练位置驱动响应＋旋转持有点模型。`ATEC_THROW_JOINT_MODEL`载入joint_response.json（无文件时是明确未标定的即时跟踪假设）。可选`ATEC_THROW_RESIDUAL`载入经过投掷标定的释放位置/速度残差；不加载旧JEPA放置预测器来打分。驱动模型不预测夹持滑脱，不能冒充完整投掷世界模型。

尚无残差检查点时是零残差的**未标定物理先验**，不是已训练投掷世界模型。夹爪延迟0.06秒同样是待实测的先验。现有抓取/放置数据不能验证自由飞行、篮沿碰撞或物体旋转。新残差训练入口fit_release_residual.py只用真实投掷日志，将连续重力一致飞行帧回推到统一的名义释放时刻，学习释放位置/速度误差；不是声称测到了精确脱离接触的时刻。

每件物体至少8个训练释放样本、3个独立种子的验证样本。只有三件物体均满足验证误差与相对零残差至少10%的改善要求，才产生可部署release_residual.json。模型绑定物理配置；不支持的参数/偏移范围返回零先验，位置和速度修正分别限于±3cm、±0.25m/s。不预测物体旋转、篮沿碰撞和入篮后的接触稳定性。

## 新成功标准与原任务隔离

入口是`scripts/throwing/run_throw_task.py`，结果标记为`TaskE-Toss-v1`。它只在自己的环境实例中关闭原“进篮即结束”条件，不修改Task E注册、场景几何或驱动源码。

独立评测需要每件物体同时具备：

1. 闭爪附近抬升、随末端运动的持有证据；
2. 张爪后向上运动；
3. 与释放位置分离、具有重力一致的自由飞行帧，且上升至少1cm；
4. 落到篮子区域，低速稳定至少25步（默认0.5秒）。

普通放置/掉落不会算作上抛成功。该评测使用位置/速度的运动学证据，不是接触力传感器证明；实际碰撞/抓取可靠性仍需Isaac检验。控制器的visual_success_only与评测throw_success分别记录，不能用视觉概率替代评测。

原play_atec_task.py会拒绝新throw_cem模式，避免把原Task E计分当作投掷成功。旧测试必须显式设置原后端。

## 已补齐采集与训练入口，真实权重仍待服务器生成

**RGB位姿模型已训练两轮但均未通过标定，不能部署。**旧JEPA任务头输出距离/高度，不输出完整物体XYZ和姿态，不能冒充新位姿头。默认构造新策略时会要求`ATEC_THROW_PERCEPTION`，没有可用模型就明确停止，不制造物体位置。

新位姿格式`atec_throw_rgb_pose_v1`，输出三件物体的XYZ、wxyz四元数与质量分数；冻结DINOv2 ViT-S/14，4×4池化特征＋24维本体输入一个256隐藏维MLP。训练和推理共享同一特征提取、RGB缩放、位置归一化和四元数解码。缓存冻结特征，默认只训练小头1500步。

采集时用--save-dataset保存pose_data.hdf5：224×224 RGB、24维本体与**同一动作前状态**的三物体XYZ/四元数，默认每5步一帧。不将下一帧位姿错配给当前图像。启动暖机帧不保存。失败轨迹也可用于感知训练，文件完成标志不等于任务成功。旧HDF5没有完整四元数标签，训练器会拒绝，不能复制初始姿态冒充运动中的标签。

train_pose.py按完整种子分训练/验证，最低2个训练种子＋1个不同的验证种子。质量头的监督是预测XYZ/姿态是否准确，而非伪造的“全部可见”标签；只用独立验证集标定阈值。每物体需要至少30个被接受帧、20%覆盖，且这些帧中至少95%满足位置误差≤1.5cm、旋转误差≤12°。它不是遮挡检测或接触证明。任一物体不通过，只保存pose_candidate.pt与诊断，不产生rgb_pose.pt。通过也仅证明这个小验证集的离线位姿质量，不能替代RGB闭环成功率。

飞行加速阶段按每步更新视觉，避免低幅上抛的顶点落在原5步采样间隔内；其他阶段仍低频更新以节省推理。最终真实落篮始终由独立评测记录。

Oracle训练模式是为了先验证动作可行性和收集释放物理数据，**不是最终RGB策略**。仅显式`--oracle-training`时位姿来自仿真真值；结果标注oracle_training_only=true，deployment_success_claim始终false。默认运行没有该替代路径。

## 下一步在Linux服务器操作

先激活现有IsaacLab环境，并设置项目源码路径；本轮没有远程执行以下命令。

先在三个不同种子上采集少量训练专用数据（以下目录名都必须是新的；本轮未执行这些命令）：

```bash
/root/IsaacLab/isaaclab.sh -p scripts/throwing/run_throw_task.py \
  --headless --oracle-training --save-dataset --seed 43 \
  --max-steps 6000 --output-dir runs/toss_seed43_NEW
# 再分别用seed44、45，输出不同目录。
# 某个物体失败会停止本回合；可加--objects 2单独采芥末瓶，避免重跑香蕉。
```

两种子训练、一个种子留作验证。需事先设置ATEC_JEPA_BUNDLE指向服务器已有含DINO权重的目录，不会自动联网下载：

```bash
python scripts/throwing/train_pose.py \
  --train-files runs/toss_seed43_NEW/pose_data.hdf5 runs/toss_seed44_NEW/pose_data.hdf5 \
  --val-files runs/toss_seed45_NEW/pose_data.hdf5 \
  --steps 1500 --cache-dir runs/toss_frozen_features \
  --output-dir runs/toss_pose_NEW
```

只有得到足够投掷释放样本，再训练残差；训练/验证目录列表由实际采集结果填写：

```bash
python scripts/throwing/fit_release_residual.py \
  --train-runs runs/CALIBRATION_TRAIN_1 runs/CALIBRATION_TRAIN_2 \
  --val-runs runs/CALIBRATION_VAL_1 \
  --output-dir runs/toss_residual_NEW
```

上面的残差目录列表只是格式示例，不足以达到每物体8＋3个释放样本；不要将普通抓取帧算作释放样本。无需保存所有后续残差试验的RGB训练集，完整trace就可用于拟合。未过标定的候选权重不应手工改calibrated标志。

真正RGB推理需要先提供新模型：

```bash
export ATEC_THROW_PERCEPTION=/absolute/path/to/calibrated_rgb_pose.pt
# 可选：export ATEC_THROW_RESIDUAL=/absolute/path/to/calibrated_release_residual.json
/root/IsaacLab/isaaclab.sh -p scripts/throwing/run_throw_task.py \
  --headless --max-steps 6000 --output-dir runs/toss_rgb_NEW
```

运行生成run_config.json、result.json与trace.jsonl；有--save-dataset才另外保存HDF5。日志中的物体真值在evaluation_only栏目，训练文件内真值明确标为training_only_truth；默认RGB策略不读取它们。遇到环境自动重置则不把重置后状态当作本回合末帧。单物体采集的requested_objects_success与三物体throw_success分开，不能混为整题成功。

回退原Task E：

```bash

```
